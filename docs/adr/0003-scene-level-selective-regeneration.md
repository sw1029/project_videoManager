# ADR-0003 장면 단위 생성과 fingerprint 기반 선택적 재생성

- 상태: 채택 (2026-11-07)

## 맥락
AC-01 은 "지정 객체의 속성만 바뀌고 비대상 객체/배경은 90% 이상 유지" 를 요구하지만, 픽셀 단위 편집은 이번 학기 Won't 다.
생성 모델은 확률적이어서 전체를 다시 만들면 비대상 요소가 함께 바뀐다.

## 결정
- 생성은 장면(Scene) 단위로 하고 `VideoAssembler` 가 이어 붙인다.
- 각 장면의 생성 조건(장면 조건 + 객체 정의 + 참조 이미지 + seed)을 해시(fingerprint)로 만들어 클립에 저장한다.
- 수정 버전은 부모의 seed·참조 이미지를 물려받고, 부모에 같은 fingerprint 의 클립이 있으면 재생성하지 않고 재사용한다.
- `PreservationChecker` 는 재사용 장면을 1.0, 재생성 장면은 측정 점수로 판정한다.

## 결과
- 비대상 장면은 바이트 동일 → 보존율의 하한이 구조적으로 보장된다.
- 바뀐 장면 수만큼만 GPU 시간이 든다 (리스크 1 완화).
- 비용: 장면 경계에서의 연속성은 별도 검수(CONSISTENCY)에 의존한다.
